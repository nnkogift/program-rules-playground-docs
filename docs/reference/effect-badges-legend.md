# Effect badges legend

This page lists every kind of rule effect the app shows, with its label, icon and colours. The same colours are used for the badges on fields, the effect badges on rule cards and in the **Trace** tab, the edges in the **Graph** tab, and the rows of the **Server effects** dialog.

## Where you see effect badges

- **On a field:** next to the field label. A field shows one badge, for the last rule effect on it in the latest evaluation. Hover over the badge to see the action type and the rule, for example "ASSIGN from rule: PRT-E07 ASSIGN number x 2 to data element". See [Read field badges and hidden-field placeholders](../using-the-app/read-field-badges-and-hidden-field-placeholders.md).
- **On a rule card in the Rules tab:** one badge per action, such as "ASSIGN · Assigned value (number x 2)". See [Find out why a rule did or didn't fire](../using-the-app/find-out-why-a-rule-did-or-didnt-fire.md).
- **In the Graph tab:** the toolbar shows the graph legend, limited to the kinds of effect on the current edges. Each edge uses the graph edge colour. See [Map rule dependencies](../using-the-app/map-rule-dependencies.md).

The field badge words (**Hidden**, **Shown**, **Assigned**, ...) are not the same as the graph legend words (**Hide**, **Show**, **Assign**, ...). Both are listed below.

## On-complete badges

**WARNINGONCOMPLETE** and **ERRORONCOMPLETE** use the warning and error colours with a dashed border, and the field badge reads **On complete: warning** or **On complete: error**. The badge shows as soon as the rule fires, not only when you complete the form. See [Test on-complete rules](../using-the-app/test-on-complete-rules.md).

## Notes

- **HIDESECTION** shows no badge. The section shows a placeholder, "Section hidden by" and the rule name, instead.
- **HIDEPROGRAMSTAGE** shows in the **Rules**, **Trace** and **Graph** tabs only. It has no effect on the form or the **Enrollment** rail.
- **UNSETMANDATORYFIELD** shows the **Required by rule** badge, because it changes whether the field is required.
