# Start over

## Goal

Clear everything you entered in the playground and start again from a blank form, without going back to the program list.

## Before you start

- You have a program open in the playground.
- You don't need anything you entered. Nothing in the playground is saved, so a reset can't be undone.

## Steps

1. In the context bar at the top right, select **Reset playground**.

![Context bar with the back link, program name, organisation unit, event date and Reset playground](./img/context-bar.png)

The reset happens straight away. There is no confirmation.

## What you'll see

**Reset playground** clears:

- The **Organisation unit**. The field is empty again.
- The **Event date** or **Enrollment date**. It goes back to today.
- Every value in every form. In a tracker program, that includes the **Enrollment form** and all stage forms.
- In a tracker program, the events you added to repeatable stages. Each repeatable stage shows "No events yet" again.
- The rule history in the **Trace** tab and the **Graph** tab, and any notice from **Validate form** or **Verify with server**.
- Settings made on the forms, such as **Show hidden fields**, which is turned on again.

The forms then load again and the rules evaluate against the empty form, as they do when you first open the program.

**Reset playground** keeps:

- The program you have open.
- Your place in the program list. **Programs** still takes you back to the same search, filter and page.
